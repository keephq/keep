## Connecting with the Provider

1. **Create a Rocket.Chat Incoming Webhook:**
   - In Rocket.Chat, go to **Administration > Workspace > Integrations**.
   - Click **New** and choose **Incoming**.
   - Enable the integration and select the channel messages should be posted to.
   - Save the integration and copy the generated **Webhook URL**, which should be passed as the `webhook_url` for authentication.

<Note>
The channel configured on the integration is used by default. Sending a `channel` value from a workflow overrides it only if
**Enable message overriding** is turned on for that integration in Rocket.Chat.
</Note>
