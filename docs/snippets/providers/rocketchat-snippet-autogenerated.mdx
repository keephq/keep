## Authentication
This provider requires authentication.
- **webhook_url**: Rocket.Chat Incoming Webhook Url (required: True, sensitive: True)



## In workflows

This provider can be used in workflows.



As "action" to make changes or update data, example:
```yaml
actions:
    - name: Query rocketchat
      provider: rocketchat
      config: "{{ provider.my_provider_name }}"
      with:
        message: {value}  # The content of the message.
        attachments: {value}  # The attachments of the message.
        channel: {value}  # The channel to send the message to, overriding the webhook default.
        alias: {value}  # Display name to post the message under.
        emoji: {value}  # Emoji to use as the avatar, e.g. ":ghost:".
        avatar: {value}  # Image url to use as the avatar.
```
