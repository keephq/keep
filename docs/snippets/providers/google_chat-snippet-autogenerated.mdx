## Authentication
This provider requires authentication.
- **webhook_url**: Default Google Chat Webhook Url. Optional when every notification passes its own webhook_url (required: False, sensitive: True)


## In workflows

This provider can be used in workflows.



As "action" to make changes or update data, example:
```yaml
actions:
    - name: Query google_chat
      provider: google_chat
      config: "{{ provider.my_provider_name }}"
      with:
        message: {value}  # The text message to send.
        webhook_url: {value}  # Webhook URL of the space to post to, overrides the one from the provider configuration.
        cards_v2: {value}  # Google Chat cardsV2 payload, can be sent with or instead of the text message.
        thread_key: {value}  # Arbitrary key that groups messages into a thread, a new thread is started if it is unknown.
```
